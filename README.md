# SportsBet Manager

Gestão e tracking pessoal de apostas esportivas: registre entradas por Telegram ou pela web, concilie saldos por casa de apostas e leia ROI de verdade.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui (tema Nocturne)
- TanStack Query, React Router
- Recharts, Phosphor Icons

## Rodando localmente

```sh
npm install
npm run dev
```

O app sobe em `http://localhost:8080`. A API que ele consome é configurada em `src/api/apiClient.ts`.

## Build de produção

```sh
npm run build
```
